> Creating,一个Minecraft服务器
------
## Creating!
### You should know
Creating（中文名「虹海」，简称 CR）是由 Creating 工程组运营的 Minecraft Java 版创造服务器，以城市建设和轨道交通为主。玩家在同一张地图上共同规划街区、建设公共设施，并通过地铁和城际铁路连接各个
诞生于2020年3月下旬，并于2020年4月1日正式开服。

### 发展沿革
Creating 于 2020 年 4 月 1 日开服，最初是一个基岩版生存服务器。2021 年，服务器从同一份存档分出创造服，保留了早期玩家建设的城区。2022 年 8 月，~~Creating携创造服加入:@{$u计划~~，并在同年秋季迁移至 Java 版，开始使用 Minecraft Transit Railway 改造既有铁路。早期的生存服现已停止运营，虹海的建设目前以创造服为主。
阅读更多：[Creating 旅行手册](https://wiki.czzzz.work/index.php?title=Creating%E6%97%85%E8%A1%8C%E6%89%8B%E5%86%8C) · [Creating服务器条目](https://wiki.czzzz.work/index.php?title=Creating)


### 城市与游戏
目前Creating主要集中于城市建设，在游戏中位于全图东南地区，虹海目前有滨海、甘地、森园、寰沙、新海、花地、卡琉佩、北野等城市。各地保留了不同阶段的建设风格，从滨海主城区早期的小尺度建筑，到森园的工业街区和新海的现代城区。我们也正在努力建设交通网络以更供玩家更方便地前往其他城市亦或其他服务器。

如您在Creating的游戏中有任何疑问或困难，您可以求助于管理员及其他玩家。Creating感谢您的对我们服务器的支持。
